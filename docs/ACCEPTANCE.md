# 红米 K70 / Android 16 / HyperOS 3 实机验收

本清单需要在用户手机上完成，不能用云端模拟器结果代替。

- [ ] 安装 APK，打开后速度位于最显眼位置，精度在下方。
- [ ] 拒绝定位权限不崩溃；允许精确定位后能进入搜索状态。
- [ ] 室外开阔处能够获得坐标、卫星图和真实速度；室内无信号时不伪造数据。
- [ ] 关闭定位或失去更新超过 10 秒后，速度不继续显示为实时数据。
- [ ] 指南针随手机方向变化，旋转屏幕仍正确；磁场干扰时能看到可靠性提示。
- [ ] 保存停车点，备注、目标方向、直线距离可用；距离接近时提示不代表精确到达。
- [ ] 记录步行 5 分钟，暂停 1 分钟，继续 5 分钟；轨迹在暂停位置断开，时间排除暂停。
- [ ] 熄屏 10 分钟、切换应用后继续记录；通知栏可暂停、继续和结束。
- [ ] 电池省电模式与应用省电策略分别测试，必要时调整无限制/自启动设置。
- [ ] 强制停止再打开后，已有轨迹保留并标为异常中断，而不是假装持续记录。
- [ ] GPX、CSV、收藏 GeoJSON 可在手机文件管理器找到并读取。
- [ ] 深色、浅色、跟随系统可切换，大字体模式无关键按钮被挡。
- [ ] 升级更高版本 APK 能覆盖安装并保留数据。

安全：请勿边驾驶边操作。直线目标箭头不是道路导航；应用不是专业测绘或救援定位设备。
