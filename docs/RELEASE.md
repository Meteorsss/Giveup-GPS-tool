# GPS 工具箱 1.0.0

面向个人使用的离线 GPS 工具箱，主要适配目标为红米 K70 / Android 16 / HyperOS 3。

## 安装
下载下面的 GPS-tool-new-1.0.0.apk，在手机上安装。不需要下载源码 ZIP。APK 使用固定签名，后续相同签名的更高版本可覆盖升级。

## 已实现
- 速度位于首页最醒目的大号仪表位置；估计水平精度在下方数据卡。
- GNSS 坐标、高度（WGS84 椭球）、卫星计数、定位时效提示。
- 卫星天空图、载噪比、星座过滤、频率和参与定位状态。
- 前台服务轨迹记录、暂停/继续、逐点保存、异常中断标记、历史与无底图预览。
- GPX（合格分段）/CSV（原始点）导出，基础跳点与静止漂移过滤。
- 位置收藏、备注、GeoJSON 导出、指南针、直线目标方向、坐标距离工具。
- 诊断和 HyperOS 设置指引，深色/浅色/跟随系统。
- 无网络权限，无账号，无广告，无遥测；关闭云备份并排除设备迁移。

## 已知边界
- 无在线地图、道路导航、GPX 导入和模拟定位功能。
- 云端 Android 16 模拟器测试不代表 K70 真实 GNSS、功耗和 HyperOS 熄屏记录已经验收。
- 首次使用请允许精确定位与通知，并在室外测试。
- 记录时保持通知可见，先做 10 分钟熄屏测试；系统强制停止或重启会中断。
- 距离与方向仅供参考，不是测绘或安全导航设备。
- 导出文件含精确位置，公开分享前请自行检查。
